# Vibe Music — Smart Shuffle Flutter App

A beautiful, fast music player with Spotify-style shuffle and synced lyrics.

## Smart Shuffle Architecture

The shuffle system (`lib/core/shuffle.dart`) implements Spotify's "Fewer Repeats" principle:

1. **POOL** — Every time a track starts, the queue is rebuilt from JioSaavn's suggestions engine and merged with the original queue (deduped, capped at 60).
2. **CANDIDATES** — 8 candidate orders, each generated by an **unbiased Fisher–Yates** shuffle + greedy no-adjacent-artist repair.
3. **SCORING** — Each complete sequence is scored for freshness, recency, artist clustering, and repetitive patterns.
4. **SELECTION** — **Temperature-weighted random selection** among candidates (not just the best), keeping it feeling human.
5. **COOLDOWN** — Recently played songs are banned from the first N positions.

## Key Features

- **Temperature-weighted candidate selection**: `temperature=0` picks the best candidate; `temperature=∞` picks uniformly random. Default `0.3` gives variety while favoring quality.
- **Cooldown ban**: Recently played songs cannot appear in the first 3 positions.
- **Look-ahead artist repair**: Greedy repair that avoids stranded artist clusters.
- **Energy curve**: Optional energy-based ordering for smooth listening arcs.
- **Fisher–Yates shuffle**: Never `sort(() => random - 0.5)` — always unbiased.
